# OMS Pro v8.3.1 Split Source

این خروجی از فایل HTML آپلودشده جدا شده است، بدون حذف قابلیت‌ها:

- `index.html` ساختار اصلی برنامه
- `assets/styles.css` استایل‌ها
- `assets/app.js` کد اصلی برنامه

نکته مهم: فایل اولیه یک خروجی Production/Bundle از React بود، نه سورس چندماژولی خام. برای جلوگیری از حذف ویژگی‌ها، من فقط آن را به فایل‌های مستقل HTML/CSS/JS تفکیک کردم و منطق برنامه را تغییر ندادم.

برای اجرا:
1. فایل `index.html` را باز کنید.
2. اگر مرورگر موبایل در اجرای فایل محلی محدودیت داشت، همین پوشه را روی هاست یا لوکال‌سرور قرار دهید.
3. دیتای Supabase و ساختار ذخیره‌سازی دست‌نخورده مانده است.
